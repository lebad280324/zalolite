**Mới**

- [x] **Trợ lý AI.** Cho Codex, Claude Code hoặc Claude Desktop trên máy đọc những hội thoại bạn chọn, rồi hỏi như "liệt kê việc tôi đã nhận mà chưa xong trong nhóm Kinh doanh 3 ngày qua". Tắt theo mặc định, chỉ đọc, không gửi được tin nhắn; tắt là dừng ngay. Bật ở Cài đặt → Trợ lý AI. Xem [hướng dẫn cài đặt](https://github.com/lebad280324/zalolite/blob/main/docs/TRO_LY_AI.md).
- [x] **Nút khóa nhanh.** Nút ⏻ trên thanh công cụ khóa Zalolite ngay; mở lại bằng Touch ID hoặc mật khẩu máy.
- [x] **Hình nền màn hình khóa.** Cài đặt → Tài khoản & khóa: dùng hình nền trò chuyện hoặc ảnh của bạn, chỉnh độ tối tùy ý. Màn hình khóa mới phủ kín cửa sổ, ẩn thanh công cụ và tiêu đề hội thoại.

**Thay đổi**

- [x] **Ưu tiên / Khác tắt theo mặc định.** Danh sách hội thoại trở lại một danh sách chung; bật lại ở Cài đặt → Tin nhắn → "Tách Ưu tiên và Khác".
- [x] **Thẻ ảnh kèm chữ gọn hơn.** Ảnh phủ kín và tràn sát mép bong bóng, chú thích nằm gọn trong bề rộng của ảnh, không còn khoảng trống hai bên.
- [x] **Tên được @tag** cùng cỡ và độ đậm với chữ xung quanh, chỉ khác màu.

**Cài đặt**

Đang dùng 0.0.11 trở lên: vào Cài đặt → Cập nhật phần mềm → **Tải và cài đặt**. Cài mới: mở DMG rồi kéo **Zalolite.app** vào **Applications**. Yêu cầu macOS 14 trở lên, chạy trên cả Mac Apple Silicon và Mac Intel.

Ứng dụng được ký ad-hoc, chưa được Apple notarize. Nếu macOS chặn lần mở đầu, dùng **System Settings → Privacy & Security → Open Anyway** sau khi đối chiếu `SHA256SUMS.txt`.

**Phạm vi kiểm tra**

Kiểm thử Rust và Swift, cầu nối worker bằng dữ liệu mẫu, quyền sở hữu thư mục dữ liệu và tính toàn vẹn gói ứng dụng. Cầu nối Trợ lý AI có kiểm thử riêng cho việc chỉ đọc hội thoại được chia sẻ, và đã được thử với Codex trên tài khoản thật. Claude Code và Claude Desktop chưa được thử trực tiếp.
